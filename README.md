# 📊 Linear & Polynomial Regression – Cancer Mortality Dataset

## 🚀 Project Overview

This project focuses on analyzing cancer mortality data and applying **Linear Regression and Polynomial Regression** techniques to understand relationships between different features and cancer mortality rates.

The main objective is to explore how regression algorithms can identify patterns in healthcare-related data and make predictions using Machine Learning.

## 🎯 Project Objectives

- Understand and analyze the Cancer Mortality Dataset.
- Perform data cleaning and preprocessing.
- Conduct Exploratory Data Analysis (EDA).
- Identify relationships between independent and dependent variables.
- Implement Linear Regression.
- Implement Polynomial Regression.
- Compare regression model performance.
- Visualize actual and predicted values.

## 🧠 Machine Learning Algorithms

### 1. Linear Regression
Linear Regression is a supervised Machine Learning algorithm used to predict continuous numerical values by identifying a linear relationship between input features and the target variable.

### 2. Polynomial Regression
Polynomial Regression extends Linear Regression by introducing polynomial features to capture nonlinear relationships between variables.

## 📈 Model Evaluation

The regression models can be evaluated using the following metrics:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

These metrics help assess prediction errors and how well the models explain variation in the target variable.
